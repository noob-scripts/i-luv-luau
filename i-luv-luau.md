# I-Luv-Luau

- i-luv-luau is an fork of the luau runtime but with more extensions that gives you more freedom with your scripts!

- This fork includes extensions such as new metamethods, new libraries, default functions improvements, extended libraries (such as debug), new and powerful functions like getgc and hookfunction!

# Additions and Extensions

## Globals

- getgc
- returns a table with all the objects collected with Luau garbage collector.
```luau
getgc(TablesIncluded: boolean): table
```
